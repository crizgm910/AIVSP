AIVSP / CONTROL DE CALIDAD

Laboratorio de formularios

Preguntas sintéticas para comprobar detección, respuesta y aplicación por separado.

Esto no es Microsoft Forms ni Teams. Reproduce controles y marcos para encontrar fallos. No garantiza compatibilidad con el DOM real de esas plataformas. No envía respuestas a ningún servidor desde esta página; AIVSP sí puede enviarlas al proveedor de IA que hayas seleccionado.

Cómo hacer la prueba
  1. Inicia AIVSP y activa la integración DOM.
  2. Desactiva PRUEBA de matrices para respuestas reales. Para probar solo el clic de una rúbrica, actívala; su selección fija no cuenta como respuesta correcta.
  3. Usa Ctrl+Shift+Y y haz clic en el enunciado o fila, no en las herramientas de registro.
  4. Verifica qué pregunta se leyó, qué respuesta produjo y qué control cambió. Registra las tres fases manualmente debajo de cada tarjeta.
  5. No todas estas clases están soportadas. Un error visible o abstención es preferible a modificar otra pregunta.
